TuringRouter OS 是一个现代化、功能强大且易于使用的路由器操作系统 。
旨在简化操作门槛，同时又能提供专业级功能。
我们的目标是将专业路由能力与现代化、易用的用户界面相结合，让普通用户和专业网络管理员都能更加轻松地管理网络。
TuringRouter OS 希望逐步实现网络设备管理、流量监控、安全策略配置以及网络基础设施管理等综合能力。
项目状态： 正在开发中。项目功能和技术架构可能随开发进度调整。
